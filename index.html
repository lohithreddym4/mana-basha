Language manual

Syntax that feels local and compiles global.

Variables

Use igo to declare values.

igo x = 10;
igo name = "Telugitha";

Booleans

Truth values are expressed with Telugu-flavored words.

nijam   -> true
abaddam -> false

igo alive = nijam;

Conditionals

okavela handles if, lekunte handles else.

okavela x > 5 {
  chupi("Greater");
} lekunte {
  chupi("Smaller");
}

Loops

Repeat work until the condition reaches varuku.

igo i = 0;

chestoone undu {
  chupi(i);
  i = i + 1;
} (i < 5) varuku

Output

Use chupi() to print visible program output.

chupi("Hello World");
chupi(10 + 20);

Arithmetic and comparisons stay familiar for fast learning.
